# Two Sum

- Platform: LeetCode
- Problem Number: 1
- Difficulty: Easy
- Topic: Arrays
- Approach: Brute Force

## Logic
Use two nested loops to check every possible pair.
If their sum equals the target, return their indices.

## Complexity
- Time Complexity: O(n^2)
- Space Complexity: O(1)

## Approach 2: HashMap

- Time Complexity: O(n) average
- Space Complexity: O(n)

Uses a HashMap to find the complement of each number.
